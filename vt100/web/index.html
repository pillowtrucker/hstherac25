      Reproducing the accidents
      
Tyler, 1986: Malfunction 54

      
    
        
  1. Type a patient name, RETURN, and RETURN again for the treatment mode.
    2. 
        
  2. BEAM TYPE: X RETURN. The energy fills in 25 and the machine starts setting its bending magnets, which takes about 8 seconds.
    3. 
        
  3. RETURN for the energy, then 200, 202 and 1, each followed by RETURN. Then press RETURN six times to copy the room settings. The cursor is now on COMMAND.
    4. 
        
  4. After 2 seconds but before 8 have passed since you typed X, press ↑ until you are back on BEAM TYPE (11 times). Type E RETURN, then RETURN back down to COMMAND.
    5. 
        
  5. When SYSTEM says BEAM READY, type B RETURN.
    6. 
      

      
The screen says ELECTRON; the machine fired X-ray current with the turntable in the electron position. The screen shows MALFUNCTION 54, TREAT PAUSE and 6 monitor units. P RETURN does it again.

      
Yakima, 1987: Class3 overflow

      
    
        
  1. Enter an X-ray prescription down to COMMAND, as above, without the edit.
    2. 
        
  2. Press FIELD LIGHT on the hand control. SYSTEM says PRESS SET BUTTON.
    3. 
        
  3. Open "What the operator couldn't see" and press SET (or type SET RETURN) when Class3 is between about 240 and 254.
    4. 
        
  4. If BEAM READY appears, type B RETURN. You get FLATNESS and no dose on the monitor.
    5. 
      

      
Keys: Enter is RETURN, Backspace is BACK SPACE, Insert is LINE FEED, F1–F4 are PF1–PF4, Scroll Lock is NO SCROLL. R RETURN resets.
